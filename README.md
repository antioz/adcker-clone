# adcker-clone

Исследовательский эксперимент: первые экраны https://adcker.com/ с теми же анимациями (Lenis-скролл, выезд строк, разрастающийся кадр, появление из размытия), свои тексты и фото, свободные шрифты с кириллицей (Jost, Noto Serif Display, Inter).

Сборка: `python3 build.py` (нужны локальные `source-adcker.html` и `source-adcker.css`, в git их нет). Запуск: `python3 -m http.server`, открыть `index.html`.
